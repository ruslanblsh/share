# share · garna

Перенос текста, картинок и файлов между устройствами по короткому коду.
Родился как мост в изолированный Cloud Browser GetSales (Ctrl+C/Ctrl+V туда не работает),
годится и просто для переброса между своими устройствами.

Один `index.html` без сборки и зависимостей. Хостинг - GitHub Pages, хранилище - Firebase
Realtime Database (бесплатный Spark: 1 ГБ данных, 10 ГБ трафика в месяц).

## Файлы репозитория

```
index.html            всё приложение
manifest.webmanifest  PWA-манифест (установка на домашний экран)
favicon.svg           иконка вкладки
icon-192.png          иконка PWA
icon-512.png          иконка PWA (и maskable)
apple-touch-icon.png  иконка для iPhone
logo.svg              (опционально) фирменный логотип - положи рядом, подхватится в шапке
```

## Правила Firebase (ОБНОВИТЬ при апдейте до этой версии)

Консоль Firebase → Realtime Database → Rules:

```json
{
  "rules": {
    "clips": {
      "$code": { ".read": true, ".write": true }
    },
    "meta": {
      ".read": true,
      "$code": { ".write": true }
    }
  }
}
```

Что изменилось: появился узел `/meta` - лёгкий индекс пакетов (код, дата, размер) для панели
«хранилище» и автоуборки. Сами пакеты по-прежнему нельзя перечислить - читаются только по
точному коду. Компромисс: список кодов в `/meta` может прочитать любой, кто знает адрес базы
(он виден в публичном репозитории). Для маркетинговых текстов приемлемо; секреты через
обменник не гонять.

## Как пользоваться

**Отправить:** текст (редактор с жирным/курсивом/списками, вставка из Word сохраняет
оформление и переносы) + картинки и любые файлы до 9 МБ на пакет - перетаскиванием, выбором
или Ctrl+V. На выходе код из 5 символов, кнопки «Копировать код» и «Ссылка» и QR-код: навёл камеру
телефона - пакет открылся сразу (QR подгружается с cdnjs; если CDN недоступен, блок просто
не показывается, остальное работает).

**Получить:** ввести код. У текста без оформления - одна кнопка «Копировать». У текста с
оформлением - «Копировать для LinkedIn» (жирный и курсив символами Unicode: 𝗧𝗮𝗸,
переживает вставку в окно поста) и «Обычный текст». У картинок - «Копировать картинку» и
«Скачать», у файлов - «Скачать файл».

**Хранилище** (ссылка в подвале): список всех пакетов с датами и размерами, удаление по
одному или всех сразу. Пакеты старше 30 дней удаляются автоматически - уборку запускает
первое открытое за сутки устройство. Пакеты, созданные до этого обновления, в списке не
видны (у них нет записи в meta) - разово посмотреть и удалить их можно в консоли Firebase:
Realtime Database → вкладка Data → узел clips.

## Установка на телефон

Сайт собран как PWA: Android/Chrome - меню → «Добавить на главный экран» (предложит сам),
iPhone/Safari - «Поделиться» → «На экран "Домой"». Открывается без адресной строки, со своей
иконкой.

## Ограничения

- Копирование картинки в буфер - Clipboard API, только HTTPS и Chromium. Не сработало - «Скачать».
- Unicode-жирный не трогает кириллицу (в этом блоке Unicode её нет), скринридеры читают его
  плохо, поиск LinkedIn по нему не ищет. Годится для заголовка, не для всего поста.
- Картинки ужимаются до 1920 px по длинной стороне; файлы летят как есть, лимит пакета 9 МБ.
- Word-мусор (`mso-*`, шрифты, кегли) вычищается при вставке; размеры и цвета шрифта не
  переносятся сознательно.
